# Kangaroo

Continuous test runner for Gleam with affected-test selection.

## Installation

```sh
git clone https://github.com/P4suta/kangaroo.git
cd kangaroo/cli
gleam deps download
```

## Usage

```sh
gleam run -m kangaroo_cli -- --help
```
